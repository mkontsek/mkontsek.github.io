# Lint and Format Skill

## Scope

Apply at the end of any agentic coding change so the result is commit-ready.

## Rules

1. Run lint with auto-fix when available.
2. Run Prettier/format after lint.
3. If lint or format reports issues, fix and rerun until clean.
4. Do not skip this step for code changes.
5. Skip only for pure documentation-only edits.
